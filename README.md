# المحاسب الذكي | Al-Muhasib AI

نموذج أولي لتطبيق محاسبي عربي بواجهة من اليمين إلى اليسار، يجمع بين متابعة الحسابات والعمليات والفواتير ومراجعة مالية بمساعدة الذكاء الاصطناعي.

## المزايا الحالية

- لوحة معلومات لمتابعة النشاط المالي.
- دليل حسابات قابل للعرض والإدارة.
- إدارة العملاء والموردين.
- متابعة فواتير البيع والشراء.
- عرض العمليات والحسابات.
- مساعد لتحليل البيانات المالية وتقديم تنبيهات وتوصيات أولية.
- حفظ بيانات الحسابات والعمليات والشركاء والفواتير محليًا في المتصفح باستخدام `localStorage`.

> **تنبيه:** هذا المشروع نموذج أولي، وليس نظامًا محاسبيًا معتمدًا أو بديلًا عن مراجعة محاسب مختص. لا تستخدمه حاليًا لحفظ بيانات مالية حقيقية أو حساسة دون إضافة حماية ونسخ احتياطي واختبارات مناسبة.

## التقنيات

- React 19
- TypeScript
- Vite
- Recharts
- Google GenAI SDK

## التشغيل محليًا

المتطلبات: Node.js و npm.

```bash
npm install
npm run dev
```

لبناء نسخة الإنتاج:

```bash
npm run build
npm run preview
```

## ملاحظة أمنية مهمة

يستدعي تكامل الذكاء الاصطناعي الحالي Google GenAI من كود الواجهة ويقرأ المفتاح عبر `process.env.API_KEY`. وضع مفتاح API داخل تطبيق يعمل في المتصفح قد يكشفه للمستخدمين، كما أن إعداد المتغير بهذه الصورة يحتاج إلى مراجعة في بيئة Vite. قبل النشر أو إدخال بيانات حقيقية، انقل طلبات الذكاء الاصطناعي إلى خادم خلفي آمن، ولا ترفع مفاتيح API إلى GitHub.

## حالة المشروع

قيد التطوير. بعض البيانات الأولية تجريبية، ويجب اختبار العمليات المحاسبية والتحقق من دقتها قبل الاعتماد عليها.
